# Student Grade Project

## About
This is a Python project that calculates student average marks and assigns a grade.

## Features
- Student name, department, and semester
- Input marks for 3 subjects
- Calculate average marks
- Assign grades based on average marks
- Display student details

## Technologies Used
- Python

## How to Run
1. Install Python.
2. Download or clone this repository.
3. Open the terminal in the project folder.
4. Run the following command:

   python student_grade.py

## Grade System
- S: 90 and above
- A: 80 and above
- B: 65 and above
- C: 50 and above
- D: 40 and above
- F: Below 40
